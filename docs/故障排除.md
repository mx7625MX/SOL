## 安装问题

### ❌ Node.js 未安装

**现象：**
```
'node' 不是内部或外部命令，也不是可运行的程序
```

**解决方案：**
1. 访问 https://nodejs.org/zh-cn/
2. 下载 LTS 版本（推荐）
3. 运行安装程序，一路"下一步"
4. 重新打开命令提示符
5. 验证安装：`node --version`

### ❌ NPM 安装依赖失败

**现象：**
```
npm ERR! code ENOENT
npm ERR! syscall open
```

**解决方案：**
```bash
# 1. 清理 npm 缓存
npm cache clean --force

# 2. 删除 node_modules
# Windows:
rmdir /s /q node_modules
rmdir /s /q package-lock.json

# 3. 重新安装
npm install

# 4. 如果还是失败，尝试使用国内镜像
npm config set registry https://registry.npmmirror.com
npm install
```

### ❌ Python 相关错误

**现象：**
```
gyp ERR! find Python
```

**解决方案：**
```bash
# 安装 Windows 构建工具
npm install --global windows-build-tools

# 或者安装 Python 3.8+
# 访问 https://www.python.org/downloads/
```

### ❌ 权限错误

**现象：**
```
Error: EACCES: permission denied
```

**解决方案：**
- Windows: 以管理员身份运行命令提示符
- 或更改项目文件夹的权限

## 启动问题

### ❌ 端口已被占用

**现象：**
```
Error: listen EADDRINUSE: address already in use :::3001
```

**解决方案：**

**方法一：修改端口**
编辑 `backend/.env`：
```env
PORT=3002  # 改为其他端口
```

**方法二：关闭占用进程**
```bash
# 查找占用端口的进程
netstat -ano | findstr :3001

# 结束进程（PID 是上一步找到的进程 ID）
taskkill /PID <PID> /F
```

### ❌ 后端启动失败

**现象：**
```
Error: Cannot find module 'xxx'
```

**解决方案：**
```bash
cd backend

# 删除依赖
rmdir /s /q node_modules

# 重新安装
npm install

# 重新启动
npm run dev
```

### ❌ 前端启动失败

**现象：**
```
Failed to resolve module
```

**解决方案：**
```bash
cd frontend

# 清理缓存
npm cache clean --force

# 删除依赖
rmdir /s /q node_modules

# 重新安装
npm install

# 重新启动
npm run dev
```

### ❌ 配置文件错误

**现象：**
```
Error: 请在.env文件中设置您的私钥
```

**解决方案：**
1. 确保 `backend/.env` 文件存在
2. 如果不存在，复制：`copy backend\.env.example backend\.env`
3. 编辑配置文件，填写必要参数

## 钱包问题

### ❌ 导入助记词失败

**现象：**
```
无效的助记词
```

**解决方案：**
1. 确保助记词是 12 或 24 个单词
2. 单词之间用**单个空格**分隔
3. 检查是否有多余的空格或换行
4. 确保所有单词都是小写
5. 验证助记词的有效性

**正确格式示例：**
```
word1 word2 word3 word4 word5 word6 word7 word8 word9 word10 word11 word12
```

### ❌ 导入私钥失败

**现象：**
```
导入私钥失败: 私钥长度不正确
```

**解决方案：**
1. **Phantom 钱包导出：**
   - 打开 Phantom 扩展
   - 设置 → 安全与隐私 → 导出私钥
   - 复制完整的 Base58 字符串（通常以数字或字母开头）

2. **欧易钱包导出：**
   - 打开欧易钱包
   - 选择 Solana 钱包
   - 导出私钥或助记词

3. **验证私钥：**
   - Base58 格式通常是 87-88 个字符
   - 不要包含空格或换行

### ❌ 钱包余额为 0

**解决方案：**
1. 确保钱包地址正确
2. 检查是否在 Mainnet（主网）
3. 给钱包转入少量 SOL
4. 刷新页面重新加载

### ❌ 钱包已存在

**现象：**
```
钱包已存在
```

**解决方案：**
- 这个钱包已经导入过了
- 如需重新导入，先删除旧钱包
- 或使用不同的标签名

## 监控问题

### ❌ 监控无法启动

**现象：**
点击"启动监控"没有反应

**解决方案：**
1. 检查后端是否正常运行
2. 查看浏览器控制台错误（F12）
3. 确保至少有一个钱包启用了监控
4. 查看后端日志：`backend/logs/monitor.log`

### ❌ 价格不更新

**现象：**
持仓价格一直不变

**解决方案：**
1. 检查 WebSocket 连接状态
2. 查看浏览器控制台是否有错误
3. 检查网络连接
4. 重启后端服务
5. 刷新前端页面

### ❌ 检测不到新买入

**现象：**
买入代币后系统没有检测到

**解决方案：**
1. 确保监控服务正在运行
2. 等待几分钟（需要时间同步）
3. 检查交易是否已确认
4. 查看后端日志确认是否检测到交易
5. 手动刷新持仓列表

### ❌ 监控频繁掉线

**现象：**
连接状态频繁变化

**解决方案：**
1. 检查网络稳定性
2. 更换更可靠的 RPC 节点
3. 增加重连间隔（修改代码）
4. 检查防火墙设置

## 交易问题

### ❌ 自动卖出不触发

**现象：**
盈利达到阈值但没有卖出

**可能原因和解决方案：**

1. **监控未启用**
   - 检查监控设置中的"启用监控"开关
   - 确保点击了"保存配置"

2. **阈值设置过高**
   - 检查盈利阈值设置
   - 当前盈利可能还未达到

3. **代币流动性不足**
   - 代币可能无法交易
   - 尝试在 Jupiter 手动交换

4. **余额不足**
   - 确保有足够的 SOL 支付手续费
   - 至少保留 0.01 SOL

### ❌ 交易失败

**现象：**
```
交易失败: Transaction simulation failed
```

**解决方案：**

1. **增加滑点容忍度**
   编辑 `backend/.env`：
   ```env
   DEFAULT_SLIPPAGE=1.0  # 增加到 1%
   ```

2. **检查余额**
   ```
   需要的 SOL = 卖出手续费 + 网络费用
   建议至少保留 0.01 SOL
   ```

3. **网络拥堵**
   - 稍后重试
   - 使用更快的 RPC 节点

4. **代币问题**
   - 代币可能被锁定或有转账限制
   - 检查代币合约

### ❌ 交易确认超时

**现象：**
```
Transaction confirmation timeout
```

**解决方案：**
1. 增加超时时间（编辑 `backend/.env`）：
   ```env
   TRANSACTION_TIMEOUT=60000  # 增加到 60 秒
   ```
2. 使用更快的 RPC 节点
3. 检查 Solana 网络状态：https://status.solana.com/

### ❌ 交易被拒绝

**现象：**
```
Transaction rejected
```

**解决方案：**
1. 检查钱包是否有足够权限
2. 验证私钥是否正确
3. 确保钱包未被锁定
4. 检查是否有足够的 SOL

## 性能问题

### ❌ 系统运行缓慢

**解决方案：**

1. **使用付费 RPC 节点**
   ```env
   RPC_ENDPOINT=https://mainnet.helius-rpc.com/?api-key=你的密钥
   ```

2. **调整更新间隔**
   编辑 `backend/src/config/index.ts`：
   ```typescript
   priceUpdateInterval: 15000,  // 从 10 秒改为 15 秒
   ```

3. **限制监控钱包数量**
   - 不要同时监控太多钱包
   - 建议最多 5-10 个

4. **清理数据库**
   - 定期删除旧的交易记录
   - 备份后删除 `backend/data/monitor.db`

### ❌ 内存占用过高

**解决方案：**
1. 重启后端服务
2. 减少监控钱包数量
3. 调整日志级别（`backend/.env`）：
   ```env
   LOG_LEVEL=error  # 只记录错误
   ```

### ❌ CPU 占用过高

**解决方案：**
1. 增加检查间隔
2. 减少并发监控数量
3. 使用更强大的服务器

## 数据问题

### ❌ 数据库损坏

**现象：**
```
database disk image is malformed
```

**解决方案：**
```bash
# 1. 停止服务
# 2. 备份数据库
copy backend\data\monitor.db backend\data\monitor.db.backup

# 3. 删除数据库
del backend\data\monitor.db

# 4. 重启服务（会自动创建新数据库）
```

### ❌ 数据不同步

**解决方案：**
1. 刷新浏览器页面（Ctrl + F5）
2. 清除浏览器缓存
3. 检查 WebSocket 连接
4. 重启后端服务

### ❌ 持仓数据丢失

**解决方案：**
1. 检查数据库文件是否存在
2. 恢复备份数据库
3. 重新导入钱包
4. 系统会自动检测新持仓

## 网络问题

### ❌ 无法连接到 RPC 节点

**现象：**
```
Failed to connect to RPC endpoint
```

**解决方案：**

1. **检查网络连接**
   - 确保能访问互联网
   - 尝试 ping api.mainnet-beta.solana.com

2. **更换 RPC 节点**
   编辑 `backend/.env`：
   ```env
   # 免费公共节点
   RPC_ENDPOINT=https://api.mainnet-beta.solana.com
   
   # 或使用其他节点
   RPC_ENDPOINT=https://solana-api.projectserum.com
   ```

3. **使用付费节点**
   - Helius: https://helius.dev/
   - QuickNode: https://www.quicknode.com/
   - Alchemy: https://www.alchemy.com/

### ❌ WebSocket 连接失败

**现象：**
前端显示"未连接"

**解决方案：**
1. 确保后端正在运行
2. 检查防火墙设置
3. 验证端口没有被占用
4. 查看浏览器控制台错误

### ❌ API 请求失败

**现象：**
```
Network Error
```

**解决方案：**
1. 确保后端在运行
2. 检查端口配置是否正确
3. 查看浏览器控制台详细错误
4. 检查 CORS 设置

## 日志分析

### 查看后端日志

```bash
# Windows
type backend\logs\monitor.log

# 查看最新的 50 行
powershell Get-Content backend\logs\monitor.log -Tail 50

# 持续监控日志
powershell Get-Content backend\logs\monitor.log -Wait -Tail 20
```

### 常见日志错误

**错误 1：**
```
Error: getaddrinfo ENOTFOUND
```
**原因：** 无法解析域名，网络问题  
**解决：** 检查网络连接和 DNS 设置

**错误 2：**
```
Error: Request timeout
```
**原因：** RPC 请求超时  
**解决：** 使用更快的 RPC 节点或增加超时时间

**错误 3：**
```
Error: Insufficient funds
```
**原因：** SOL 余额不足  
**解决：** 向钱包转入更多 SOL

## 紧急恢复

### 完全重置系统

如果遇到无法解决的问题，可以完全重置：

```bash
# 1. 备份数据库（如果需要）
copy backend\data\monitor.db backup\monitor.db.backup

# 2. 停止所有服务
scripts\停止监控机器人.bat

# 3. 删除所有依赖和数据
rmdir /s /q backend\node_modules
rmdir /s /q frontend\node_modules
del backend\data\monitor.db
del backend\.env

# 4. 重新安装
scripts\启动监控机器人.bat
```

### 恢复备份数据

```bash
# 停止服务
scripts\停止监控机器人.bat

# 恢复数据库
copy backup\monitor.db.backup backend\data\monitor.db

# 重新启动
scripts\启动监控机器人.bat
```
