# Solana 链上全自动监控机器人 🤖

一个功能完整的 Solana 链上代币自动监控和交易系统，提供前后端完整实现，适配 Windows 环境，界面与注释全部中文，专为零基础用户设计。

## ✨ 核心功能

### 1. 钱包管理
- ✅ 支持助记词导入（12/24个单词）
- ✅ 支持私钥导入（Base58格式）
- ✅ 完美兼容 Phantom 钱包导出格式
- ✅ 完美兼容欧易（OKX）钱包导出格式
- ✅ 钱包信息加密存储，确保安全

### 2. 智能监控
- ✅ 自动监听指定钱包的新 Token 买入事件
- ✅ 实时检测持仓 Token 当前盈利比例
- ✅ 持续更新市价，精确计算盈亏
- ✅ 监控其他钱包的大额买入行为

### 3. 自定义参数
- ✅ 盈利百分比阈值（例如 30%，可调）
- ✅ 监控同代币其它钱包买入金额阈值（如 1 SOL，可调）
- ✅ 自动卖出时的卖出比例（10%～100%，可调）
- ✅ 所有参数支持前端界面实时配置

### 4. 自动交易
- ✅ 检测到盈利达标，2000ms 内自动卖出
- ✅ 监控到其它买家大额买入时，2000ms 内自动卖出
- ✅ 速度优先，使用 Jupiter 聚合器确保最佳价格
- ✅ 详细的日志反馈，记录所有交易细节

### 5. 前端界面
- ✅ React + Ant Design 组件库
- ✅ 全中文界面，零英文
- ✅ 监控状态看板，实时数据展示
- ✅ 参数配置面板，直观易用
- ✅ 交易日志显示，完整记录
- ✅ 响应式设计，适配各种屏幕

## 🚀 快速开始（零基础版）

### 第一步：安装 Node.js

1. 访问 Node.js 官网：https://nodejs.org/zh-cn/
2. 下载 LTS（长期支持）版本
3. 双击安装包，一路点击"下一步"完成安装
4. 打开命令提示符（按 `Win + R`，输入 `cmd`，回车）
5. 输入 `node --version` 验证安装，应该显示版本号

### 第二步：下载项目

**方法一：使用 Git（推荐）**
```bash
# 如果已安装 Git
git clone https://github.com/mx7625MX/SOL.git
cd SOL
```

**方法二：直接下载**
1. 访问 https://github.com/mx7625MX/SOL
2. 点击绿色的 "Code" 按钮
3. 选择 "Download ZIP"
4. 解压到任意文件夹

### 第三步：安装后端依赖

```bash
# 进入后端目录
cd backend

# 安装依赖（首次运行需要几分钟）
npm install

# 复制配置文件
copy .env.example .env
```

### 第四步：配置后端

用记事本或任意文本编辑器打开 `backend/.env` 文件，修改以下内容：

```env
# Solana RPC 配置（建议使用付费节点以获得更好性能）
RPC_ENDPOINT=https://api.mainnet-beta.solana.com
WS_ENDPOINT=wss://api.mainnet-beta.solana.com

# 服务器配置（保持默认即可）
PORT=3001
HOST=localhost

# 数据库配置（保持默认即可）
DB_PATH=./data/monitor.db

# 日志配置（保持默认即可）
LOG_LEVEL=info
LOG_FILE=./logs/monitor.log

# 交易配置
DEFAULT_SLIPPAGE=0.5      # 滑点容忍度 0.5%
MAX_RETRY=3               # 最大重试次数
TRANSACTION_TIMEOUT=30000 # 交易超时时间（毫秒）
```

### 第五步：启动后端服务

```bash
# 在 backend 目录下执行
npm run dev
```

看到以下信息表示后端启动成功：

## 📖 使用教程

### 1. 导入钱包

1. 点击左侧菜单 "钱包管理"
2. 点击右上角 "导入钱包" 按钮
3. 选择钱包类型：
   - **助记词**：选择此项，粘贴您的 12 或 24 个助记词
   - **私钥**：选择此项，粘贴 Base58 格式的私钥
   - **Phantom 钱包导出**：从 Phantom 钱包导出的格式
   - **OKX 欧易钱包导出**：从欧易钱包导出的格式
4. 输入钱包标签（可选，例如："我的交易钱包"）
5. 点击 "导入" 按钮

**安全提示：**
- 私钥和助记词将被加密存储在本地数据库
- 永远不要将私钥分享给任何人
- 建议使用专门的交易钱包，不要使用主钱包

### 2. 配置监控参数

1. 点击左侧菜单 "监控设置"
2. 选择要配置的钱包
3. 设置监控参数：
   - **盈利百分比阈值**：例如设置 30，表示盈利达到 30% 时自动卖出
   - **大额买入阈值**：例如设置 1.0，表示检测到有人买入超过 1 SOL 时触发卖出
   - **卖出比例**：例如设置 100% 表示全部卖出，50% 表示卖出一半
4. 开启 "启用监控" 开关
5. 点击 "保存配置" 按钮

### 3. 启动监控

1. 在 "监控设置" 页面
2. 点击右上角 "启动监控" 按钮
3. 系统将开始监控所有已启用的钱包
4. 监控状态会显示为 "运行中"

### 4. 查看监控状态

1. 点击左侧菜单 "监控看板"
2. 实时查看：
   - 总持仓数
   - 盈利持仓数
   - 平均盈亏
   - 每个持仓的详细信息
3. 数据每 10 秒自动更新

### 5. 查看交易历史

1. 点击左侧菜单 "交易历史"
2. 选择要查看的钱包
3. 查看所有买入和卖出记录
4. 点击 "查看详情" 可在 Solscan 上查看交易详情

### 使用付费 RPC 节点

免费的公共 RPC 节点可能会限速，建议使用付费 RPC 服务：

**Helius（推荐）**


**其他选项：**
- QuickNode: https://www.quicknode.com/
- Alchemy: https://www.alchemy.com/
- Triton: https://triton.one/


## 🆘 故障排除

### 后端无法启动

**问题：** 提示端口已被占用
```
Error: listen EADDRINUSE: address already in use :::3001
```

**解决：**
1. 修改 `backend/.env` 中的 `PORT=3001` 改为其他端口
2. 或关闭占用端口的程序

**问题：** 无法连接到 RPC 节点
```
Error: Failed to connect to RPC endpoint
```

**解决：**
1. 检查网络连接
2. 更换 RPC 节点地址
3. 尝试使用付费 RPC 服务

### 前端无法启动

**问题：** 依赖安装失败
```
npm ERR! code ENOENT
```

**解决：**
```bash
# 清理缓存
npm cache clean --force

# 删除 node_modules
rmdir /s /q node_modules

# 重新安装
npm install
```

**问题：** 无法连接到后端
```
Network Error
```

**解决：**
1. 确保后端服务正在运行
2. 检查后端端口是否正确
3. 查看浏览器控制台错误信息

### 交易失败

**问题：** 交易一直失败

**可能原因和解决：**
1. **余额不足**：确保钱包有足够的 SOL
2. **滑点过小**：增加 `DEFAULT_SLIPPAGE` 值
3. **网络拥堵**：使用更快的 RPC 节点
4. **代币流动性不足**：避免交易流动性极低的代币

### 监控不工作

**问题：** 持仓价格不更新

**解决：**
1. 检查 WebSocket 连接状态
2. 查看后端日志 `backend/logs/monitor.log`
3. 确保监控服务已启动
4. 重启后端和前端服务

### 常见问题（FAQ）

**Q: 机器人会 24/7 自动运行吗？**
A: 是的，只要后端服务保持运行，监控就会持续进行。建议在稳定的服务器上运行。

**Q: 可以同时监控多个钱包吗？**
A: 可以，您可以导入多个钱包，每个钱包都可以独立配置监控参数。

**Q: 私钥安全吗？**
A: 私钥在本地加密存储，不会上传到任何服务器。但请确保您的电脑安全。

**Q: 交易费用是多少？**
A: 每笔交易需要支付 Solana 网络费用（通常 0.000005 SOL）和 Jupiter 交换费用（约 0.2%）。

**Q: 可以在 Mac 或 Linux 上运行吗？**
A: 可以，项目支持所有主流操作系统。安装步骤类似，只是命令略有不同。

## 🎯 最佳实践

### 1. 参数设置建议
- **盈利阈值**：建议设置 20-50%，太低频繁交易，太高可能错过机会
- **大额买入阈值**：根据代币市值设置，建议 0.5-2 SOL
- **卖出比例**：新手建议 100% 全部卖出，老手可以分批卖出

### 2. 监控策略
- 不要贪心，及时获利了结
- 设置合理的止损点（例如 -20%）
- 避免在网络拥堵时交易
- 关注代币的基本面和社区活跃度

### 3. 资金管理
- 每笔交易不超过总资金的 10%
- 保留足够的 SOL 用于交易费用
- 定期提取利润到冷钱包
- 不要投入全部资金

### 4. 安全建议
- 定期备份数据库文件
- 使用强密码保护电脑
- 安装杀毒软件
- 不要在公共网络使用
- 不要分享私钥或助记词
