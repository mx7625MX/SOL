## 技术架构

### 后端技术栈
```
Node.js + TypeScript
├── Express (HTTP服务器)
├── WebSocket (实时通信)
├── Better-SQLite3 (数据持久化)
├── @solana/web3.js (区块链交互)
├── @solana/spl-token (Token操作)
├── bip39 (助记词处理)
├── ed25519-hd-key (密钥派生)
├── Winston (日志系统)
└── axios (HTTP请求)
```

### 前端技术栈
```
React + TypeScript
├── Ant Design (UI组件库)
├── Vite (构建工具)
├── axios (API请求)
├── dayjs (日期处理)
└── WebSocket (实时通信)
```

### 数据库设计
```sql
-- 钱包表
wallets (id, address, encrypted_key, label, created_at)

-- 持仓表
positions (id, wallet_address, token_mint, token_symbol, 
           buy_price, current_price, amount, profit_percent, status)

-- 监控配置表
monitor_configs (id, wallet_address, profit_threshold, 
                 big_buy_threshold, sell_ratio, enabled)

-- 交易记录表
transactions (id, wallet_address, token_mint, type, 
              amount, price, signature, status, timestamp)
```
