# 快速上手指南（5分钟版）

本指南帮助您在 5 分钟内快速启动和使用 Solana 监控机器人。

## 前置条件

✅ Windows 10 或更高版本  
✅ 已安装 Node.js（[下载地址](https://nodejs.org/zh-cn/)）  
✅ 有一个 Solana 钱包（Phantom 或欧易）  
✅ 钱包中有少量 SOL（用于交易）

## 一、快速启动（3个步骤）

### 步骤 1：下载项目

**方法一：使用 Git**
```bash
git clone https://github.com/mx7625MX/SOL.git
cd SOL
```

**方法二：直接下载**
1. 访问 GitHub 页面
2. 点击绿色 "Code" 按钮 → "Download ZIP"
3. 解压到文件夹

### 步骤 2：一键启动

双击运行：`scripts/启动监控机器人.bat`

首次运行会自动：
- ✅ 安装所有依赖（可能需要 3-5 分钟）
- ✅ 创建配置文件
- ✅ 启动后端和前端服务
- ✅ 自动打开浏览器

### 步骤 3：导入钱包

1. 浏览器会自动打开 `http://localhost:3000`
2. 点击左侧菜单 "钱包管理"
3. 点击 "导入钱包" 按钮
4. 选择您的钱包类型并粘贴私钥或助记词
5. 点击 "导入"

**🎉 恭喜！您已完成基础设置！**

## 二、开始监控（2个步骤）

### 步骤 1：配置监控参数

1. 点击左侧菜单 "监控设置"
2. 选择您导入的钱包
3. 设置参数：
   ```
   盈利百分比阈值：30%（推荐新手）
   大额买入阈值：1.0 SOL（根据需要调整）
   卖出比例：100%（全部卖出）
   ```
4. 打开 "启用监控" 开关
5. 点击 "保存配置"

### 步骤 2：启动监控

1. 还是在 "监控设置" 页面
2. 点击右上角蓝色 "启动监控" 按钮
3. 看到状态变为 "运行中"

**✅ 监控已启动！系统会自动工作**

## 三、查看运行状态

### 监控看板
- 点击左侧 "监控看板"
- 实时查看所有持仓
- 自动更新价格和盈亏

### 交易历史
- 点击左侧 "交易历史"
- 查看所有买卖记录
- 每笔交易都有详细日志

### 持仓管理
- 点击左侧 "持仓管理"
- 查看所有代币持仓
- 实时盈亏计算

## 四、工作原理

```
您买入代币 
    ↓
机器人检测到买入
    ↓
创建持仓记录
    ↓
每5秒检查一次价格
    ↓
盈利达到30%? ——是→ 自动卖出！
    ↓ 否
检测到大额买入? ——是→ 自动卖出！
    ↓ 否
继续监控...
```

## 六、常见问题速查

### Q1: 启动脚本报错？
**A:** 运行 `scripts/系统检查.bat` 检查环境

### Q2: 导入钱包失败？
**A:** 
- 检查助记词是否完整（12或24个单词）
- 检查私钥格式是否正确
- Phantom 钱包：设置 → 导出私钥
- 欧易钱包：选择导出助记词或私钥

### Q3: 监控不工作？
**A:**
1. 确保点击了 "启动监控" 按钮
2. 确保钱包已开启 "启用监控"
3. 检查后端日志：`backend/logs/monitor.log`

### Q4: 自动卖出不触发？
**A:**
- 确保代币盈利已达到设置的阈值
- 检查代币是否有足够流动性
- 查看交易日志是否有错误

### Q5: 如何停止服务？
**A:** 
- 方法一：运行 `scripts/停止监控机器人.bat`
- 方法二：直接关闭后端和前端的命令窗口
- 方法三：在界面点击 "停止监控"

## 七、安全提示

⚠️ **重要：请务必遵守以下规则**

1. **✅ 使用专用钱包**
   - 创建一个新钱包专门用于交易
   - 不要使用存放大量资金的主钱包

2. **✅ 控制投资金额**
   - 只投入您能承受损失的金额
   - 建议单次交易不超过总资金的10%

3. **✅ 备份私钥**
   - 妥善保存您的助记词和私钥
   - 不要分享给任何人
   - 建议写在纸上保存

4. **✅ 定期提现**
   - 获得盈利后及时提现到冷钱包
   - 不要让大量资金长期停留在交易钱包

5. **✅ 保持警惕**
   - 新代币风险极高，很多是骗局
   - 避免 FOMO（害怕错过），理性投资
   - 设置合理的止损点

## 九、性能优化建议

### 使用付费 RPC 节点
免费节点速度慢且不稳定，建议使用：

**Helius（推荐）**
1. 注册：https://helius.dev/
2. 获取免费 API Key
3. 编辑 `backend/.env`：
   ```env
   RPC_ENDPOINT=https://mainnet.helius-rpc.com/?api-key=你的密钥
   WS_ENDPOINT=wss://mainnet.helius-rpc.com/?api-key=你的密钥
   ```

### 调整滑点设置
网络拥堵时，适当增加滑点容忍度：
```env
DEFAULT_SLIPPAGE=1.0  # 增加到1%
```
